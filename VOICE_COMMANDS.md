# Label Printer — Voice Command Quick Reference

Speak into any Assist entry point (companion app mic, Assist dialog, Voice PE).
`X` = whatever the label should say. `N` = number of copies (1–20).

## Basic label

| Say | Prints |
|---|---|
| "print a label that says **X**" | X |
| "print **X** on a label" | X |
| "make a label saying **X**" | X |
| "label **X**" | X |

## Text + today's date

| Say | Prints |
|---|---|
| "print a label with today's date that says **X**" *(most reliable)* | X / date |
| "print a dated label saying **X**" | X / date |
| "print a label saying **X** with the date" | X / date |

## Date only (no text)

| Say | Prints |
|---|---|
| "print a label with the date" | date |
| "print a dated label" | date |
| "print today's date" | date |
| "print **2** labels with the date" | 2 × date |
| "print **2** dated labels" / "print **2** date labels" | 2 × date |
| "print the date on **2** labels" | 2 × date |
| "print **two** copies of today's date" | 2 × date |

## Multiple copies

| Say | Prints |
|---|---|
| "print **N** labels saying **X**" | N × X |
| "print **N** copies of a label saying **X**" | N × X |
| "print **N** labels with the date that say **X**" | N × X / date |
| "print **N** dated labels saying **X**" | N × X / date |

## Date and time

| Say | Prints |
|---|---|
| "print a label with the date and time that says **X**" | X / date time |
| "print a label with the date and time" | date time |
| "print **N** labels with the date and time" | N × date time |
| "print a label with the time saying **X**" | X / time |

## Expiry / use-by date

| Say | Prints |
|---|---|
| "print a label that says **X** expiring in **3** days" | X / date + 3 days |
| "print a label saying **X** good for **2** weeks" | X / date + 2 weeks |
| "print a label saying **X** expires **5** days from now" | X / date + 5 days |
| "print **N** labels saying **X** expiring in **1** week" | N × X / date + 1 week |

Days or weeks: 1–90 · also "use within 3 days", "keeps for 2 weeks", "lasts 5 days"

## Mix and match

- **Start:** print · make · make me · create · give me · I need · I want
- **"label":** a label · the label · label · labels
- **Before the text:** that says · saying · says · reading · with the text · with the words · for
- **Date:** today's date · the date · the current date · date
- **Polite filler is OK:** "can you…", "please", "…on it", "thank you"
- **Numbers:** "2" or "two" · "a couple of labels" = 2

## Tips

- Put the date **before** the text for the most reliable results:
  "…with today's date that says X" works better than "…X with the date".
- Assist still understands common mishearings: "level"/"table" for *label*,
  "to"/"too" for *two*.
- Text like "save the date" prints as written. The date is added only when it
  comes after **with / and / plus**.
